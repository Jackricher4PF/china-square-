# China Square - Online Clothing Store

A full-stack e-commerce store with Admin CRUD operations and Paystack international card payments.

## Setup Instructions

1. **Move Project**: Place the `china-square` folder inside your XAMPP web directory: `C:\xampp\htdocs\china-square`.
2. **Database Import**:
   - Open `http://localhost/phpmyadmin`.
   - Create a database or run all SQL statements from `schema.sql`.
3. **Configure Database & Paystack**:
   - Open `config/db.php` and set your MySQL database credentials and Paystack keys.
4. **Access Website**:
   - Storefront: `http://localhost/china-square/public/index.php`
   - Admin Login: `admin@chinasquare.com` | Password: `Password123!`
